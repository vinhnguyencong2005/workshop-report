# Harvest Report "FCAJ Community Day & Agentic AI Build Week: AI Solution Building on AWS"

### Purpose of the Event

- **Explore Real-world AI Agent Use Cases:** Gain practical insights from team presentations demonstrating Agentic AI applications across automated ordering, security monitoring, and technical engineering support.
- **Learn Multi-channel Architecture Design:** Understand design patterns for embedding AI agents directly within messaging apps like Zalo and Messenger without requiring users to switch apps.
- **Experience the 24h Hackathon Journey:** Discover authentic stories, time-sensitive pressures, and engineering lessons gained from building functional MVPs in 24 hours.
- **Automate Engineering Workflows (SA):** Examine AI-native solutions designed to automate requirement extraction, architecture diagram generation, and AWS budget estimation.

### Key Highlights

#### KFC Bot Agent Project: Multi-channel Ordering AI Agent (One Team)

- **The Lost Order Problem:** Forcing users out of chat apps to install food delivery apps creates high drop-off rates. AI ordering is challenging because conversational text is unstructured while business logic (discounts, variants, cart states) requires absolute precision.
- **Ordering Without Leaving the Chat:** Deploying an AI agent inside Zalo/Messenger enables customers to order food within ongoing chats without creating new accounts or changing apps.
- **5-Step Agent Loop:** Analyzed the team's operational flow: *Goal* → *Plan* → *Tools* → *Act* → *Verify*.
- **"Design Once, Deploy Everywhere":** Implementing standard Adapter/Connector layers allows adding new messaging channels without refactoring core business code.

#### S.H.E.P.H.E.R.D Project: Crowd Monitoring & Security Alerts (3KA Team)

- **24-Hour Hackathon Journey:** Shared realistic hackathon challenges: late-night coding, consuming energy drinks, fixing accidental `.env` credential commits on GitHub, and debugging until early morning.
- **Event Camera Monitoring:** Replacing manual gate checks, the team integrated YOLO + ByteTrack vision models with AI agents to track crowd density and estimate wait times.
- **Operator Copilot Assistant:** Allows security operators to query system metrics using natural language and receive real-time incident handling recommendations.

#### SA Professional AI Native App: Automated Assistant for Solutions Architects (Plan V Team)

- **Solving SA Pain Points:** Solved time-consuming manual tasks for Solutions Architects, such as reviewing long specs, drawing system diagrams, and calculating AWS pricing.
- **Automated Design Workflow:** The app parses raw text or audio requirements to generate editable Draw.io/AWS architecture diagrams and directional AWS budget estimates in minutes.

#### Signal Scout Project: Corporate Restructuring Signal Platform (Dream AI Team)

- **Connecting Scattered Data:** Combined Web Crawlers with analytical AI agents to collect market news, financial movements, and early warnings on corporate restructuring.
- **Execution Takeaway:** Emphasized that building a compact, functional product delivers far more value than designing an overly ambitious, non-operational concept.

### Key Takeaways

- **AI Agent Mindset:** An autonomous agent goes beyond simple Q&A chatbots by interacting with external tools and validating real-world results.
- **Flexible System Architecture:** Using Adapter design patterns allows smooth integration with existing chat platforms like Zalo without requiring app installations.
- **Hackathon Lessons:** *"A functional small product beats an unexecuted grand vision"*, demonstrating the importance of team collaboration under strict deadlines.
- **Engineering Automation:** Leverage AI tools to eliminate repetitive engineering tasks such as requirement analysis and system diagramming.

### Practical Applications

- **AI Agent Execution:** Apply the 5-step agent execution loop (Goal - Plan - Tools - Act - Verify) when designing automated enterprise AI assistants.
- **Messaging App Integration:** Integrate solutions directly into established messaging channels like Zalo to minimize user friction.
- **Workflow Optimization:** Use AI-driven tools to rapidly draft initial architecture diagrams and estimate AWS infrastructure costs for project proposals.

Event 2

Summary Report: “FCAJ Community Day June 2026: Experience-sharing session on a comprehensive topic”

Event Objectives

  • Practical DevOps Insights: Gain clear understanding of the core responsibilities, practical engineering mindset, and technical skills necessary for a DevOps Engineer.
  • Hands-On System Design: Master architectural design principles and system modeling to build a scalable URL shortener service.
  • Journey to AWS Partnership: Learn key growth milestones and personal strategies on evolving from an FCAJ community member into an official AWS Partner.
  • Navigating Multinational Cultures: Explore real-world experiences on adapting and growing within multinational corporate work environments.

Speakers

  • Trong H. Truong: DevOps Engineer @ Endava Vietnam.
  • Trung Kien Dinh: Lead Developer at startup & Minh Tho Nguyen: Student.
  • Hoang Hieu Nghi Danh: AI Engineer – AWS Community Builder – AWS Student Builder Group Leader.
  • Dat Pham: Data Analytics Engineer & Cuong Nguyen: Process Engineer.

Key Highlights

A Comprehensive Overview of a DevOps Engineer

  • Analyzing common public misconceptions about DevOps (treating it merely as basic server management or deployment support) versus actual engineering workflows.
  • Reviewing the speaker’s self-driven learning journey, practical roadmap, and skill development milestones.
  • Key principles, technical standards, and engineering practices that distinguish senior DevOps practitioners.

Building a URL Shortener Service with Serverless Architecture on AWS

  • Addressing the challenges of managing and sharing long, complex web links.
  • Designing an efficient, highly available URL shortener application utilizing AWS Serverless services like Lambda, CloudFront, and AWS WAF.

Journey of Impact: From FCAJ Member to AWS Partner

  • Key career milestones starting from joining FCAJ events, landing an initial role, and developing foundational cloud experience.
  • Contributing actively as an AWS Student Builder Group leader to mentor and support university students.
  • Expanding professional reach by joining the AWS Community Builder program and progressing step-by-step toward becoming an AWS Partner.

Data Analyst Stories: From Real-World Practice to Corporate Culture in Multinational Corporations

  • Contrasting Data Analyst roles across two different organizational environments: a high-growth startup (Kamereo) vs. a global enterprise (Colgate-Palmolive).
  • Practical frameworks to build core analytical thinking skills adaptable across varied business models.
  • Deep insights into organizational dynamics, executive expectations, and the strategic positioning of data professionals.

Key Takeaways

  • DevOps: Developing process management and systems thinking is far more critical than simply mastering individual command-line tools.
  • URL Shortener (AWS): Enhancing user experience begins with solving focused problems using lean, serverless cloud architectures.
  • Growth Journey: Sustainable career progression relies on continuous community contributions and proactive professional networking.
  • Data Analyst: Success requires an adaptable analytical mindset to solve business problems and navigate distinct corporate cultures.

Applying to Work

  • DevOps (Process & Systems Thinking): Prioritize identifying workflow bottlenecks before selecting new tools. Standardize the delivery pipeline first, then choose automation tools that align with that flow.
  • Serverless (Solving Niche Problems Leanly): Avoid building monolithic systems prematurely. Start by building a lightweight serverless prototype to address team pain points cost-effectively.
  • Growth Journey (Impact & Networking): Share technical learnings publicly. Contributing value to your community creates valuable networking channels and career growth opportunities.
  • Data Analyst (Mindset & Culture Fit): Align analytical insights directly with key business objectives and company culture. Data generates value when communicated in executive terms.

Event Experience

Participating in this event provided valuable practical insights covering technical engineering solutions, cloud design patterns, career progression, and enterprise dynamics:

Learning from Industry Experts

  • Clarified the actual role and daily responsibilities of a DevOps Engineer beyond common industry misconceptions.
  • Adopted practical self-study roadmaps and technical standards shared by experienced engineering leads.
  • Gained valuable career lessons from a Senior Data Analyst sharing hands-on corporate experience.

Hands-On Technical Experience

  • Analyzed system design patterns by working through the real-world problem of link shortening.
  • Understood how to combine Serverless compute, global content delivery, and web security into a unified architecture.
  • Evaluated how components interact to achieve high throughput and low-latency response times.

Applying Modern Tools

  • Utilized the AWS Serverless ecosystem including AWS Lambda, Amazon CloudFront, and AWS WAF for application delivery.
  • Understood how to leverage cloud services to improve security, reduce operational costs, and automate deployments.

Networking and Community Connection

  • Recognized the value of community engagement through the speaker’s growth journey from student member to AWS Partner.
  • Connected with industry speakers and peers to exchange perspectives on data engineering and corporate culture.

Key Takeaways

  • Specializing in engineering roles requires structured self-learning, hands-on practice, and an adaptable business mindset.
  • Leveraging serverless infrastructure provides a fast, cost-efficient path to solving production challenges.
  • Active involvement in technical communities accelerates professional development and career opportunities.

Kết quả đạt được sau tuần 1

  • Nắm vững khái niệm điện toán đám mây, mô hình hoạt động và cách AWS tổ chức hạ tầng toàn cầu (Regions, Availability Zones)
  • Đăng ký thành công tài khoản AWS và kích hoạt gói hỗ trợ $100 credit
  • Hoàn thành 18 bài lab thực hành AWS bao phủ các nhóm dịch vụ chính:
    • Identity & Cost: IAM (users, groups, roles, policies), AWS Budgets, AWS Support
    • Networking: VPC (subnets, route tables, Internet Gateway, NAT), Route 53 DNS, Networking on AWS Workshop nâng cao
    • Compute: EC2 (launch, connect, security groups), IAM Roles for EC2, EC2 Auto Scaling (launch templates, ASG, scaling policies)
    • Storage & Database: S3 static website hosting, RDS MySQL, DynamoDB NoSQL, ElastiCache Redis caching
    • Monitoring & Edge: CloudWatch (dashboards, alarms, logs), CloudFront CDN, Lambda@Edge cho edge computing
    • Developer Tools: AWS Cloud9 IDE, AWS CLI command-line operations
  • Xây dựng nền tảng kiến thức vững chắc về networking, compute, storage, database và monitoring trên AWS — làm tiền đề cho dự án Terraform IaC ở các tuần tiếp theo
